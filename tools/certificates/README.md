# CHIEF Certificates of Authenticity

Approved design (Oct 2026): A5 landscape, Noto Serif, gold frame — reproduced exactly by `make_certificate.py`.

Issue one for every sold copy of a numbered edition (Premium / Open After Midnight: 25 in total per work;
Super Premium: 7 in total per work, across all sizes and finishes).

- Certificate ID: `CHIEF-<tier>-<artwork no. 3 digits>-<copy 2 digits>` (SP = Super Premium, PR = Premium, AM = Open After Midnight).
- Artwork No. = the work's id on the site.
- `issued.json` is an anonymous ledger (no collector names) so copy numbers never repeat.
- **Never commit collector names or generated PDFs to this public repository.** Also update `soldEditions` for the work on the site.
